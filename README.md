## 本次修复的问题

| 问题 | 原因 | 现在怎么修好的 |
| --- | --- | --- |
| **1. 有的答案正确却被判为错误** | 教师端单选题答案存的是字母（A/B/C/D），学生端却拿「选项文字」去比较；判断题答案 A/B 与「正确/错误」文本永远不相等；填空题只做小写去空格，全角/单位/中文数字/等价分数都会判错 | 统一「答案判定引擎」：字母 / 下标 / 选项原文三种写法互通；判断题归一化 `A/B、对/错、√/×、T/F、true/false`；填空题做全半角归一、去单位、数值等价（0.5 = 1/2 = 二分之一）、中文数字（含壹贰叁）、英文单复数容错；答案为空时不再崩溃 |
| **2. 老师创建班级后没立刻弹出班级码；老师可以当作学生加入班级** | 创建后没有把班级码回显给老师；又没有区分身份，老师也能走学生入口 | 教师端「创建班级」提交后**立刻弹出班级码弹窗**（大字显示 + 一键复制班级码 / 邀请链接，班级卡片里也常驻班级码）；引入**学生 / 老师身份切换**，老师身份下「加入班级」会被拦截并提示「老师账号不能作为学生加入班级」 |
| **3. 发布作业不能从题库选题** | 原版没有把题库接到作业发布流程 | 「教师端 → 作业管理 → 发布作业」：填标题、选班级，然后**从题库按学科 / 题型 / 难度筛选并勾选题目**组成作业；需要新题先到「题库管理 → 新增题目」，保存后即可选中，作业题目统一来自题库 |
| **4. 学生端登录不上去** | 进站即要求班级码，可老师还没建班、或学生手上没有码，就完全卡在门外 | 新增**独立登录页**：学生只要填昵称就能进入（班级码选填，没有码也能点「先进入体验」），有码时自动校验并加入班级；老师的入口不需要班级码 |
| **5. 页面里混着一堆别人的测试账号** | 内置了「三年级 1 班 / 四年级 1 班」等演示班级和一批演示学生、还预置了初始积分 | 全部删除：默认不再创建任何班级、演示学生和初始积分，榜单里**只出现真实进入的人**；老版本浏览器里缓存的旧数据会在升级后自动清掉 |
| **6. 学生端 / 教师端入口重复、切换麻烦** | 导航里同时挂着「学生端」和「教师端」两个入口，容易点错 | 导航简化为「首页 · 我的课堂 · 实时榜单 · 使用解说」，学生端和教师端共用「我的课堂」；顶栏一个**学生 / 老师胶囊开关**一键切换，另有「退出」用于换账号 |
| **7. 答题时机不对：跑着跑着自己弹题** | 原来在跑道上放了一个「答题门」物件，碰到就弹题，和「躲障碍」的玩法混在一起 | 改成**撞到建筑才会弹出题目**：建筑就是障碍物，撞上就出题；**换道或跳跃躲开建筑就不会出题**；答对建筑当场爆金币 |
| **8. 金币来得太容易** | 路上散落金币、通关还有金币奖励 | 金币**只来自答对题目**（建筑爆金币），并且**题目越难金币越多**：基础 10 / 巩固 20 / 冲刺 30，连击再叠加成，BOSS 大厦 ×3；答错只扣血不给金币 |
| **9. 身份可以互相切换** | 顶栏一个开关就能从学生切到老师，老师也能进学生端，容易被学生看到教师功能 | **身份只在登录页确定**：学生进不了教师端、老师进不了学生端，直接改地址也会被拦住；顶栏只留「退出」，想换身份要先退出重新登录 |

## 打开方式

**方式一（推荐）· 长期公开网址**

直接访问 <https://suxi622.github.io/parkour-academy/>。榜单走**云端实时中继**：浏览器直连公网，静态托管也能多端同步。

**方式二 · 本机带后端的网址（局域网内多设备同步）**

```bash
node server/server.js --port 8080
```

浏览器打开 <http://127.0.0.1:8080/index.html>。这个方式会同时启动**同源后端**（REST + SSE），同一局域网内多台设备打开同一网址即可实时同步。

**方式三 · 直接双击 `index.html`**

离线也能完整运行（自动回退到本机实时模拟数据）。

## 实时榜单是怎么做到「多设备同步」的

前端启动时按顺序探测，自动选择最好的数据源：

| 优先级 | 模式 | 触发条件 | 同步方式 |
| --- | --- | --- | --- |
| 1 | **remote** | 检测到同源后端 `/api/health` | REST 上报 + SSE 实时推送（局域网 / 云主机部署） |
| 2 | **cloud** | 检测到公网中继 `ntfy.sh` 可达 | 浏览器直连公网主题：上报用 POST，接收优先走 SSE，被代理缓冲时 4 秒内自动切换为 3 秒轮询 |
| 3 | **local** | 两者都不可用 | 本机实时模拟，离线也能完整演示 |

顶栏右上角会显示当前数据源：`🟢 实时后端` / `🌐 云端实时` / `🟡 本地模拟`。

**想要一个只属于本班的榜单**：在网址后面加 `?topic=房间名`，例如
`https://suxi622.github.io/parkour-academy/?topic=class-5-3-abc`，把这个带参数的网址发给学生，大家就只会在同一个独立榜单里比拼，不会和其他班混在一起。

> 说明：云端中继用的是开源消息服务 ntfy.sh 的公共主题，方便零成本分发；若学校有隐私要求，建议用「方式二」在自己的服务器上部署同源后端。

## 功能地图

- **登录页** `#/login`：学生 / 老师共用一个入口（学生填昵称即可进入，班级码选填；老师不需要班级码）。**身份在这里一次性确定，之后不能互相切换**，要换身份先「退出」
- **首页** `#/home`：介绍、学科入口、实时榜单预览与动态流
- **我的课堂** `#/my`：按当前身份进入学生端或教师端（身份在登录页选定，不可互切）
- **学生端** `#/student`：加入班级、待完成作业、个人面板、学科与难度选择、实时榜单
- **跑酷闯关** `#/student/game/:subject/:difficulty`：三跑道伪 3D 跑酷；**撞到建筑才出题**，答对爆金币（越难越多），躲开建筑不出题，冲过终点结算；每个学科一套专属场景
- **班级作业** `#/student/game/homework/:id`：完成老师布置的作业，完成后回传成绩
- **错题修复** `#/student/game/wrong`：答错自动收录，答对自动移出
- **我的家园** `#/student/garden`：家园房间（可布置摆件）、伙伴买 / 升级 / 出战、徽章与赛道主题
- **伙伴聊天** `#/student/chat`：和出战伙伴对话（本地陪伴模式 / 可接入大模型）
- **数据中心** `#/student/data`：正确率环形图、近 7 天积分趋势、学科掌握度、闯关记录
- **实时积分榜单** `#/leaderboard`：今日 / 本周 / 总榜、学科筛选、领奖台、名次升降、实时动态
- **教师端** `#/teacher`：班级学情（创建班级 / 班级码 / 导出成绩）、作业管理（题库选题发布）、题库管理、答案判定引擎自检、课堂竞速
- **使用解说** `#/guide`：完整图文玩法说明

## 换成你自己的后端

前端只依赖一个数据源接口，`api.js` 里 `createAdaptive()` 已经把远端实现封装好。想换成自己的服务：

1. `api.js` 中 `post('/api/join' | '/api/answer' | '/api/profile')` 的地址；
2. `/api/leaderboard` 返回结构保持 `{ ok, at, online, entries: [{ id, name, emoji, klass, isBot, points:{today,week,total}, subjectPoints, streak, online }], events: [...] }`，UI 无需改动。

题目来源同理：把 `PK.QUESTION_BANK` 换成接口返回的题目数组即可，判定仍走 `PK.grade(question, 学生作答)`。
